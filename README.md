# HR Data Analysis Project (Python)

## Overview
This project performs HR data analysis using Python (Pandas & Matplotlib) to generate insights about employees.

## Key Insights
- Salary analysis by department
- Employee attrition tracking
- Performance evaluation
- Experience vs salary trends

## Visualizations
- Department salary chart
- Attrition chart
- Experience vs salary scatter plot

## Tools Used
- Python
- Pandas
- Matplotlib
- OpenPyXL

## Purpose
Built as a Data Analyst portfolio project to demonstrate real-world HR analytics skills.
